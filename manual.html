    Ausgangslage und Ziele

    NOWE (steht im übrigen für NOie WErsion (neue Version), dabei ist die neue Version von PIFAS gemeint) stellt Abfahrtstabellen mit Live-Daten zur Verfügugn.

    Zielpublikum

    Das Zielpublikum sind vor allem das erweiterte private Umfeld des Autors. Zu weit sollte das Tool nicht verbreitet werden, da die API ein Limit hat.

  • Begriffe und Definitionen

    • Namensherkunft

    Die Urpsrungsidee war, eine Abfahrtstabelle von JETZT (engl. NOW) zu haben. Da NOW alleine eher nach einem Zeitserver o.ä. klingt und Namen mit zwei Silben aber nur vier Buchstaben durchaus cool klingen, habe ich mich anschliessend für NOWE entschieden. Dabei kann der Name, wie oben erwähnt auch als NOie WErsion in der Miimsprache gedeutet werden.

Suchfeld

Suchfeld

Das Suchfeld ist das zentrale Element der Hauptseite. Es ermöglicht die Suche nach einer Station, um die Abfahrtstabelle dieser Station zu sehen.

Abkürzungen

Folgende Eingaben sind möglich:

  • SLOID
  • DiDok-ID
  • Haltestellennamen als normaler Text
  • Abkürzungen

Es sind die meisten DiDok-Abkürzungen hinterlegt (Stand Mai 2026).

Hinweis: Es ist zu beachten, dass bei der Eingabe eines Abkürzung die verknüfpten Stationen absichtlich nicht berücksichtigt werden.

Einige Abkürzungen sind auch manuell programmiert und werden als sogenanntes "Secret" (Aussprache: "Sekret" oder "Siikrett") bezeichnet.

Verschiedenes

    Versionen und History

    Da es sich eigentlich um ein Privatprojekt handelt, ist die neuste Version auch immer die PROD-Version.
    Dies hat den Nachteil, dass für externe User ggf. auch fehlerhafte Funktionen auftauchen

    Ältere stabile oder instabile Versionen werden im Unterordner /history abgelegt und sind nicht weiter dokumentiert.

    Fehlermeldungen

    Seit Anfang Juni 2026 ist der grösste Teil des Codes von NOWE auf GitHub verfügbar.
    Fehler und Wünsche können über das Issue-Tracker-System mitgeteilt werden.

    Verbindungsabbruch

    Es kann vorkommen, das die Webapp aus ungeklärten Gründen die Verbindung zum Server oder zur API verliert. In diesem Fall hilft in der Regel ein kurzer Reload der Seite.
    Dass der Browser (oder WebClip etc.) Verbindung zur WebApp verliert ist auch möglich, dies ist jedoch dem Gerät verschuldet. Dies ist erkennbar daran, dass die Uhrzeit sich nicht mehr aktualisiert.

Favoriten

Standardmässig sind ein paar wenige Favoriten vordefiniert. Selbstverständlich kann man weitere hinzufügen oder bestehende löschen. Dies funktioniert jedoch nur auf dem jeweiligen Gerät, da die Favoriten als "ojp_favs" im Local storage des Browsers gespeichert werden.

Hinzufügen von Favoriten

  1. Gewünschte Station suchen
  2. Stern/Favorit-Button drücken

Löschen von Favoriten

  1. Favorit anwählen
  2. erneut auf Favorit klicken
  3. löschen bestätigen
    4. Alternativ kann auch lange auf den Favorit-Button gedrückt werden. (Langes Drücken funktioniert nur auf Desktopgeräten.)

Bild anzeigen

Inkludierte Stationen

includedStations

Das ist eine Liste mit Verknüpfungen von Stationen.
Diese Liste beinhaltet vor allem die Verknüpfung von Bahnhöfen und der dazugehörenden Haltestelle "Bahnhof" (frz. "gare", rumantsch "staziun", it. "stazione").
Um die Verknüpfungen zu ändern, muss die Liste neu erstellt werden. Dazu gibt es zum Glück Hilfskonverter.

Verknüpfte Stationen

combinedStations

Das ist eine Liste mit Verknüpfungen von Stationen. Gründe für Verknüpfungen können ganz unterschiedlich sein. In der Regel handelt es sich um Haltestellen in der Nähe oder Alternativhaltestellen.

Hinweis: combinedStations überschreiben mögliche includedStations!

Kann ich mithelfen?

JA! Mach eine Liste an den zu verknüpfenden Stationen. Das verpflichtende Format findest du im Wiki.

GitHub

Am besten ist es, wenn du auf GitHub ein entsprechendes Issue eröffnest oder die combinedStations gleich selbst ergänzt.

Formation

Die Formationsanzeige ist erreichbar über nowe.stellwerksim.ch/formation. Die Eingabe des EVU ist nicht unbedingt nötig. Es werden automatisch die verfügbaren EVUs durchgerechnet.

Mit der Ergänzung ?train=1234 kann auch direkt über die URL eine Zugsformation abgefragt werden.

  • EVU: Eingabe des EVU-spezifischen Kürzels (optional)
  • Zugnummer: Eingabe der Zugnummer
  • Eingabe eines anderen Datums (optional)
Die Formationsanzeige funktioniert derzeit as it is und wird in der nächsten Zeit noch grafisch überarbeitet.

Swiss Journey ID

In der Ansicht der Chain wird u.a. die Swiss Journey ID angezeigt. Mit einem Klick darauf wird sie in die Zwischenablage kopiert.

Die SJYID wird beim Abfragen eines Trips benötigt.

Trip

Die Trip-Ansicht ist erreichbar über nowe.stellwerksim.ch/trip. Dort kann die SJYID eingegeben werden, um die Trip-Ansicht zu sehen.
